# Hello

A minimal example that writes a greeting in the current directory.

- **Prerequisites** — Sir and a writable working directory.
- **Inputs** — Required `name`, the person or label to greet.
- **Output** — Creates or replaces `greeting.txt`.
- **Run** — Install `hello.yml` using the [registry instructions](../../README.md), then run `sir run hello --non-interactive --input=name=Sir`.
